Projets

Pipeline de trafic maritime (AIS)

Ingère des données de suivi de navires depuis la NOAA ou des fichiers CSV, élimine les positions invalides et les doublons, calcule la distance parcourue et le temps à quai, puis charge le tout dans PostgreSQL. Un service FastAPI et un tableau de bord Streamlit l'exploitent, et Airflow peut planifier les chargements. Le tout tourne avec Docker Compose.

Python, PostgreSQL, FastAPI, Streamlit, Airflow, Docker

Banc d'essai ETL vs ELT : Pandas vs dbt

Construit deux fois le même schéma en étoile à partir des données TPC-H, une fois en ETL avec Pandas et DuckDB, une fois en modèles dbt sur DuckDB, puis compare le temps d'exécution, le CPU, la mémoire et le débit à plusieurs échelles. Compare aussi les tests de qualité, la complexité du code et le lignage.

Python, Pandas, DuckDB, dbt, Plotly

Code sur GitHub

Pipeline météo avec Airflow

Un DAG Airflow qui récupère en parallèle sept jours de météo depuis l'API Open-Meteo pour Montréal et Paris, fusionne et transforme les résultats avec Pandas, puis les enregistre. Projet de cours, exécuté avec Docker Compose.

Airflow, Python, Pandas, Docker

Prévision de séries temporelles avec des LSTM

Des réseaux LSTM profonds en TensorFlow et Keras pour prévoir des séries temporelles, l'approche que j'utilise en analyse prédictive pour mes clients.
