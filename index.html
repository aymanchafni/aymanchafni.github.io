Maritime traffic pipeline (AIS)

Ingests ship-tracking data from NOAA or CSV files, removes invalid positions and duplicates, computes distance travelled and time at dock, and loads it into PostgreSQL. A FastAPI service and a Streamlit dashboard sit on top, and Airflow can schedule the loads. Everything runs with Docker Compose.

Python, PostgreSQL, FastAPI, Streamlit, Airflow, Docker

ETL vs ELT benchmark: Pandas vs dbt

Builds the same star schema from TPC-H data twice, once as a Pandas and DuckDB ETL and once as dbt models on DuckDB, then compares them on run time, CPU, memory and throughput across data scales. It also weighs data-quality tests, code complexity and lineage.

Python, Pandas, DuckDB, dbt, Plotly

Weather data pipeline with Airflow
